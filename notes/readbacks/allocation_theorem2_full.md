## Parsing and convention facts used below (checked against library source)

- **Sum notation.** The body of `∑ x ∈ s, body` is parsed at precedence 67. It therefore absorbs `*` and `/` (precedence 70) and `^`, but not `+`, `-` (65) or relations. So `∑ i ∈ s, V i / n i ≤ τ` means $\big(\sum_{i\in s}V_i/n_i\big)\le\tau$, and `∑ ℓ ∈ 𝓛, Y ℓ (N ℓ) ω - μ[P]` means $\big(\sum_{\ell\in\mathcal L}Y_{\ell,N_\ell}(\omega)\big)-\mu[P]$.
- **`if` inside a subtraction.** `a - if c then x else y` parses as $a-(\text{if }c\text{ then }x\text{ else }y)$.
- **Real arithmetic.** $\sqrt{x}=0$ for $x\le 0$; $x/0=0$; $0^{-1}=0$. A real power with a real exponent is `Real.rpow`: for $x>0$, $x^{y}=e^{y\ln x}$. Also $0^{0}=1$ and $0^{y}=0$ for $y\neq0$; a negative base gives a junk value involving $\cos(\pi y)$.
- **Integrals.** $\mu[f]$ is the Bochner integral $\int f\,d\mu$. It is $0$ whenever $f$ is not $\mu$-integrable.
- **`IsLeast A a`** means $a\in A$ and $a\le x$ for every $x\in A$, i.e. a minimum that is attained.
- **`HasSum f a`** (default summation filter `unconditional`) means that the finite partial sums $\sum_{b\in F}f(b)$ converge to $a$ along the net of all finite sets $F$ directed by inclusion. This is order-independent (unconditional) summation. For real-valued $f$ it is equivalent to absolute summability together with the sum being $a$.
- **`atTop` on multi-indices.** On $\mathbb N^D$ with the componentwise order, `atTop` is generated by the up-sets $\{k: k\ge a\}$. Because this order is directed, a set belongs to `atTop` iff it contains such an up-set. So "$\to$ along `atTop`" means: for all $\delta>0$ there is $n_0$ such that the property holds for every $k$ with **all** $k_d\ge n_0$, i.e. as $\min_d k_d\to\infty$. For $D=0$ the index type has a single point, and `atTop` is the whole-space (principal `univ`) filter.
- **`Pairwise r`** means $r(i,j)$ for all $i\neq j$.
- **`MemLp f 2 μ`** means $f$ is a.e.-strongly measurable and $\int|f|^2\,d\mu<\infty$.
- **`IndepFun f g μ`** means the $\sigma$-algebras generated by $f$ and $g$ are independent under $\mu$. Here $\mathbb R$ carries its Borel $\sigma$-algebra.
- **`variance X μ`** is the real number $\big(\int^{-}|X-\mu[X]|^2\,d\mu\big)$ converted from $[0,\infty]$ to $\mathbb R$; the value $\infty$ becomes $0$. For $X\in L^2$ of a probability measure it is the usual variance.

# Packet 5

Context: $\iota$ is an arbitrary type and $s$ is a finite subset of $\iota$. $V,C:\iota\to\mathbb R$ are arbitrary real functions, with no sign assumptions unless a hypothesis states one. All "allocations" $n:\iota\to\mathbb R$ are **real-valued**: there is no integrality and no rounding anywhere in this packet. Empty sums are $0$.

## `sumSqrtVC` (definition)

For a finite set $s\subseteq\iota$ and $V,C:\iota\to\mathbb R$,
$$\operatorname{sumSqrtVC}(s,V,C)=\sum_{i\in s}\sqrt{V_i\,C_i}.$$

- $\sqrt{\cdot}$ is the real square root, which is $0$ at negative arguments. A term with $V_iC_i<0$ therefore contributes $0$ rather than being undefined.
- For $s=\varnothing$ the value is $0$.

## `lagrangeN` (definition)

For $s$, $V$, $C$ as above, a real number $\tau$, and **every** $i\in\iota$ (not only $i\in s$):
$$N_i:=\operatorname{lagrangeN}(s,V,C,\tau)(i)=\tau^{-1}\cdot\sqrt{V_i/C_i}\cdot\sum_{j\in s}\sqrt{V_jC_j}.$$

Junk and edge values:
- If $\tau=0$ then $\tau^{-1}=0$ and $N\equiv0$.
- If $C_i=0$ then $V_i/C_i=0$ and $N_i=0$.
- If $V_i/C_i<0$ then the square root is $0$ and $N_i=0$.
- If $\tau<0$ then $N_i\le0$.

$N_i$ is a real number, not rounded.

## `lagrangeN_variance_cost`

**Data (all implicit):** the type $\iota$; a finite set $s\subseteq\iota$; functions $V,C:\iota\to\mathbb R$; a real $\tau$.

**Definitions used, expanded:**
$$S:=\sum_{j\in s}\sqrt{V_jC_j},\qquad N_i=\tau^{-1}\sqrt{V_i/C_i}\;S,$$
with $\sqrt{x}=0$ for $x\le0$, $x/0=0$ and $0^{-1}=0$.

**Hypotheses, in order:**
1. $s\neq\varnothing$.
2. $V_i>0$ for every $i\in s$.
3. $C_i>0$ for every $i\in s$.
4. $\tau>0$.

**Conclusion (both conjuncts):**
$$\sum_{i\in s}\frac{V_i}{N_i}=\tau\qquad\text{and}\qquad\sum_{i\in s}N_i\,C_i=\tau^{-1}\Big(\sum_{i\in s}\sqrt{V_iC_i}\Big)^2 .$$

**Remarks:**
- Under the hypotheses, $S>0$ and $N_i>0$ for $i\in s$, so no division-by-zero convention is triggered on $s$.
- Both claims are exact equalities; in particular the first sum equals $\tau$, not merely $\le\tau$.
- Values of $V$, $C$, $N$ outside $s$ play no role.
- Non-emptiness is used: for $s=\varnothing$ the first sum would be $0\neq\tau$.
- The hypotheses are satisfiable (e.g. $s=\{i\}$, $V_i=C_i=\tau=1$), so the statement is not vacuous.

## `lagrangeN_unique`

**Data:** implicit $\iota$, $s$, $V$, $C$, $\tau$ as above; an explicit function $n:\iota\to\mathbb R$, introduced after the first three hypotheses.

**Definitions used, expanded:** $N_i=\tau^{-1}\sqrt{V_i/C_i}\sum_{j\in s}\sqrt{V_jC_j}$, with the conventions above.

**Hypotheses, in order:**
1. $\tau>0$.
2. $V_i>0$ for every $i\in s$.
3. $C_i>0$ for every $i\in s$.
4. (the function $n$ is given)
5. $n_i>0$ for every $i\in s$.
6. $\displaystyle\sum_{i\in s}\frac{V_i}{n_i}\le\tau$ (inequality).
7. $\displaystyle\sum_{i\in s}n_iC_i=\tau^{-1}\Big(\sum_{i\in s}\sqrt{V_iC_i}\Big)^2$ (equality).

**Conclusion:** for every $i\in s$, $n_i=N_i=\tau^{-1}\sqrt{V_i/C_i}\sum_{j\in s}\sqrt{V_jC_j}$.

**Remarks:**
- There is no non-emptiness hypothesis. For $s=\varnothing$, hypotheses 6–7 hold automatically ($0\le\tau$, $0=0$) and the conclusion is an empty universal statement, so that case is trivially true.
- Only the values of $n$ on $s$ are determined; $n$ is unconstrained off $s$.
- The statement does **not** by itself say that $\tau^{-1}S^2$ is the least achievable cost. It says: any positive real allocation that meets the variance bound (with $\le$) and whose cost is **exactly** $\tau^{-1}S^2$ agrees with $N$ on $s$.

## `optimal_cost_isLeast`

**Data:** explicit $s$ (finite subset of $\iota$) and $V,C:\iota\to\mathbb R$; implicit real $\tau$.

**Definitions used, expanded:** $S=\sum_{j\in s}\sqrt{V_jC_j}$ and $N_i=\tau^{-1}\sqrt{V_i/C_i}\,S$ for all $i\in\iota$.

**Hypotheses, in order:**
1. $\tau>0$.
2. $s\neq\varnothing$.
3. $V_i>0$ for every $i\in s$.
4. $C_i>0$ for every $i\in s$.

**Conclusion:** a conjunction of three parts. Let
$$\mathcal C_\tau=\Big\{c\in\mathbb R:\ \exists\,n:\iota\to\mathbb R,\ \big(\forall i\in s,\ n_i>0\big)\ \wedge\ \sum_{i\in s}\frac{V_i}{n_i}\le\tau\ \wedge\ c=\sum_{i\in s}n_iC_i\Big\}.$$

- **(a)** $\tau^{-1}S^2$ is the least element of $\mathcal C_\tau$. That is, some real allocation $n$, positive on $s$ and with $\sum_{i\in s}V_i/n_i\le\tau$, has cost $\sum_{i\in s}n_iC_i=\tau^{-1}S^2$, and every such allocation has cost $\ge\tau^{-1}S^2$.
- **(b)** $N_i>0$ for all $i\in s$, $\sum_{i\in s}V_i/N_i=\tau$, and $\sum_{i\in s}N_iC_i=\tau^{-1}S^2$.
- **(c)** For every $n:\iota\to\mathbb R$: if $n_i>0$ on $s$, $\sum_{i\in s}V_i/n_i\le\tau$ and $\sum_{i\in s}n_iC_i=\tau^{-1}S^2$, then $n_i=N_i$ for every $i\in s$.

**Remarks:**
- The optimisation is over real-valued $n$ (a continuous relaxation), with the variance constraint as an inequality $\le\tau$.
- Uniqueness in (c) holds only on $s$.
- Part (c) has the same content as `lagrangeN_unique`, and (b) the same as `lagrangeN_variance_cost` plus positivity.
- Not vacuous.

## `optimal_variance_isLeast`

**Data:** explicit $s$, $V$, $C$; implicit real $B$.

**Notation:** $S=\sum_{j\in s}\sqrt{V_jC_j}$ and $n^\ast_i:=\dfrac{B\sqrt{V_i/C_i}}{S}$. This allocation is written out directly in the statement, not via `lagrangeN`. Mathematically it equals $\operatorname{lagrangeN}(s,V,C,S^2/B)(i)$.

**Hypotheses, in order:**
1. $B>0$.
2. $s\neq\varnothing$.
3. $V_i>0$ for every $i\in s$.
4. $C_i>0$ for every $i\in s$.

**Conclusion:** a conjunction of three parts. Let
$$\mathcal V_B=\Big\{v\in\mathbb R:\ \exists\,n:\iota\to\mathbb R,\ \big(\forall i\in s,\ n_i>0\big)\ \wedge\ \sum_{i\in s}n_iC_i\le B\ \wedge\ v=\sum_{i\in s}\frac{V_i}{n_i}\Big\}.$$

- **(a)** $B^{-1}S^2$ is the least element of $\mathcal V_B$. It is attained by some positive real allocation with cost $\le B$, and no such allocation has variance sum below it.
- **(b)** $\displaystyle\sum_{i\in s}\Big(\frac{B\sqrt{V_i/C_i}}{S}\Big)C_i=B$. The explicit allocation spends exactly the budget.
- **(c)** For every $n:\iota\to\mathbb R$: if $n_i>0$ on $s$, $\sum_{i\in s}n_iC_i\le B$ and $\sum_{i\in s}V_i/n_i=B^{-1}S^2$, then $n_i=\dfrac{B\sqrt{V_i/C_i}}{S}$ for every $i\in s$.

**Remarks:**
- Part (b) on its own asserts only the budget identity. It does not state $n^\ast_i>0$ or that the variance of $n^\ast$ equals $B^{-1}S^2$. Those follow jointly: (a) supplies some attaining allocation, and (c) forces it to equal $n^\ast$ on $s$.
- $S>0$ under the hypotheses, so no division by zero occurs.
- Real-valued allocations; the budget constraint is an inequality.
- Not vacuous.

## `twoLevel_optimal_ratio`

**Data (all implicit):** real numbers $V_0,V_1,C_0,C_1,B,n_0,n_1$.

**Hypotheses, in order:**
1. $V_0>0$.
2. $V_1>0$.
3. $C_0>0$.
4. $C_1>0$.
5. $B>0$.
6. $n_0>0$.
7. $n_1>0$.
8. $n_0C_0+n_1C_1=B$.

**Conclusion (an equivalence):**
$$\Big[\ \forall m_0,m_1\in\mathbb R:\ m_0>0\Rightarrow m_1>0\Rightarrow m_0C_0+m_1C_1=B\Rightarrow \frac{V_0}{n_0}+\frac{V_1}{n_1}\le\frac{V_0}{m_0}+\frac{V_1}{m_1}\ \Big]\iff\ \frac{n_1}{n_0}=\frac{\sqrt{V_1/C_1}}{\sqrt{V_0/C_0}} .$$

**Remarks:**
- The left side says $(n_0,n_1)$ minimises $V_0/m_0+V_1/m_1$ among positive **real** pairs with **exactly** the same cost $B$. Pairs with smaller cost are not compared.
- Hypothesis 5 ($B>0$) is redundant: it follows from 3, 4, 6, 7 and 8.
- All divisions and square roots have positive arguments, so no junk values arise.
- Not vacuous.

# Packet 6

Context: $D\in\mathbb N$ is implicit. Multi-indices are $\ell=(\ell_0,\dots,\ell_{D-1})\in\mathbb N^D$ (functions `Fin D → ℕ`), ordered componentwise. $e_d$ is the $d$-th unit multi-index, and $e_T=\sum_{d\in T}e_d$ for $T\subseteq\{0,\dots,D-1\}$. Where a probability or measure $\mu$ is present, $\mathbb E[f]$ below abbreviates the Bochner integral $\int f\,d\mu$ (the Lean `μ[f]`). It is $0$ whenever $f$ is not integrable.

## `dot` (definition)

For $a:\{0,\dots,D-1\}\to\mathbb R$ and $\ell\in\mathbb N^D$:
$$\operatorname{dot}(a,\ell)=a\cdot\ell=\sum_{d=0}^{D-1}a_d\,\ell_d ,$$
with each $\ell_d$ cast from $\mathbb N$ to $\mathbb R$. For $D=0$ it is $0$.

## `crossDiff` (definition)

For $p:\mathbb N^D\to\mathbb R$ and $\ell\in\mathbb N^D$, the value $\Delta p(\ell):=\operatorname{crossDiff}(p)(\ell)$ is defined by recursion on $D$.

- **$D=0$:** $\Delta p(\ell)=p(\ell)$, where $\ell$ is the empty tuple.
- **Dimension $D+1$:** write $\ell=(\ell_0,\ell')$ with $\ell'=(\ell_1,\dots,\ell_D)$, and let $\Delta'$ be the $D$-dimensional operator. Then
$$\Delta p(\ell)=\Delta'\big[m\mapsto p(\ell_0,m)\big](\ell')\;-\;\begin{cases}0,&\ell_0=0,\\[2pt]\Delta'\big[m\mapsto p(\ell_0-1,m)\big](\ell'),&\ell_0\ge1.\end{cases}$$
  The whole case expression is subtracted.

The natural-number subtraction $\ell_0-1$ is only evaluated when $\ell_0\ge1$, so it never truncates.

Unfolding the recursion gives the closed form
$$\Delta p(\ell)=\sum_{T\subseteq\{d:\ \ell_d\ge1\}}(-1)^{|T|}\,p(\ell-e_T).$$
This is the first-order mixed backward difference in every direction; directions with $\ell_d=0$ are not differenced.

Examples:
- $D=1$: $\Delta p(0)=p(0)$ and $\Delta p(\ell)=p(\ell)-p(\ell-1)$ for $\ell\ge1$.
- $D=2$ with $\ell_0,\ell_1\ge1$: $p(\ell_0,\ell_1)-p(\ell_0-1,\ell_1)-p(\ell_0,\ell_1-1)+p(\ell_0-1,\ell_1-1)$.

A consequence of the definition, not itself stated in these packets: $\sum_{\ell\le k}\Delta p(\ell)=p(k)$ for every $k\in\mathbb N^D$ (telescoping over the box $\{0..k_0\}\times\cdots\times\{0..k_{D-1}\}$).

## `mimcEta` (definition; requires $D\neq0$ through `[NeZero D]`)

For $\alpha,\beta,\gamma:\{0,\dots,D-1\}\to\mathbb R$:
$$\eta(\alpha,\beta,\gamma)=\max_{0\le d<D}\ \frac{\gamma_d-\beta_d}{\alpha_d}.$$
The maximum is `Finset.sup'` over the nonempty index set; it exists because $D\ge1$. With the convention $x/0=0$, a direction with $\alpha_d=0$ contributes the value $0$.

## `mimcD2` (definition; requires $D\neq0$)

$$D_2(\alpha,\beta,\gamma)=\#\Big\{d\in\{0,\dots,D-1\}:\ \frac{\gamma_d-\beta_d}{\alpha_d}=\eta(\alpha,\beta,\gamma)\Big\}\in\mathbb N .$$
It is the number of directions attaining the maximum. Since the maximum of a nonempty finite family is attained, $1\le D_2\le D$.

## `mimcD3` (definition)

$$D_3(\alpha,\beta)=\#\{d\in\{0,\dots,D-1\}:\ \alpha_d=\beta_d/2\}\in\{0,\dots,D\}.$$

**Observation:** `mimcD3` is not referenced by any statement in packets 5–6, including `giles_theorem2_full`.

## `mimcBound` (definition)

For reals $\eta,e_1,e_2,\varepsilon$:
$$\operatorname{mimcBound}(\eta,e_1,e_2,\varepsilon)=\begin{cases}\varepsilon^{-2}, & \eta<0,\\[2pt] \varepsilon^{-2}\,|\ln\varepsilon|^{e_1}, & \eta=0,\\[2pt] \varepsilon^{-2-\eta}\,|\ln\varepsilon|^{e_2}, & \eta>0,\end{cases}$$
where all powers are real powers (`rpow`).

- $e_1$ matters only when $\eta=0$, and $e_2$ only when $\eta>0$.
- For $0<\varepsilon<e^{-1}$ we have $\ln\varepsilon<-1$, so $|\ln\varepsilon|>1$. The bound is then positive and finite, and strictly increasing in $e_1$ (resp. $e_2$): larger exponents give a larger, i.e. weaker, bound.
- Outside that range Lean returns junk values ($\ln 0=0$, `rpow` of a negative base, $0^{x}$ conventions). The theorem below only uses $\varepsilon\in(0,e^{-1})$.

## `tendsto_sum_box_integral_crossDiff`

**Data:**
- implicit $D\in\mathbb N$ (any value, including $0$);
- an implicit type $\Omega$ with a $\sigma$-algebra;
- an implicit measure $\mu$ on $\Omega$ — **arbitrary**, not assumed finite or probability;
- explicit $P:\Omega\to\mathbb R$;
- an explicit family $(P_\ell)_{\ell\in\mathbb N^D}$ of functions $\Omega\to\mathbb R$.

**Definitions used, expanded:**
$$\Delta P_\ell(\omega):=\operatorname{crossDiff}\big(m\mapsto P_m(\omega)\big)(\ell)=\sum_{T\subseteq\{d:\ell_d\ge1\}}(-1)^{|T|}P_{\ell-e_T}(\omega),$$
computed pointwise in $\omega$ (recursive definition as in `crossDiff`).

**Hypotheses, in order:**
1. $P$ is $\mu$-integrable.
2. $P_\ell$ is $\mu$-integrable for every $\ell\in\mathbb N^D$.
3. For every $\delta>0$ there is $n_0\in\mathbb N$ such that every $\ell$ with $\ell_d\ge n_0$ for **all** $d$ satisfies $\big|\int(P_\ell-P)\,d\mu\big|<\delta$.

**Conclusion:** writing $\operatorname{Box}(k)=\{0,\dots,k_0\}\times\cdots\times\{0,\dots,k_{D-1}\}$ (Lean: `Fintype.piFinset (fun d => range (k d + 1))`),
$$\sum_{\ell\in\operatorname{Box}(k)}\int\Delta P_\ell\,d\mu\ \longrightarrow\ \int P\,d\mu\qquad\text{as }k\to\infty\text{ along `atTop` of }\mathbb N^D .$$
Concretely: for every $\delta>0$ there is $a\in\mathbb N^D$ such that every $k\ge a$ (componentwise) makes the box sum $\delta$-close to $\int P\,d\mu$. Equivalently, this holds for all $k$ with $\min_dk_d$ large enough. It says nothing about boxes that are long in some directions but short in others.

**Remarks:**
- By the telescoping consequence of the definition and linearity of the integral (all $P_\ell$ integrable), the box sum equals $\int P_k\,d\mu$. Given hypotheses 1–2, the conclusion is therefore equivalent to hypothesis 3 (take $a=(n_0,\dots,n_0)$ one way and $n_0=\max_d a_d$ the other); the substantive content is the telescoping identity. This is close to a restatement of hypothesis 3, but it is not vacuous.
- **$D=0$:** $\mathbb N^0$ is a single point $\varnothing$, `atTop` is the whole-space filter, and the conclusion reads $\int P_\varnothing\,d\mu=\int P\,d\mu$. Hypothesis 3 forces this, since its condition "for all $d$" is empty.

## `hasSum_integral_crossDiff`

**Data:**
- implicit $D$, $\Omega$ with a $\sigma$-algebra, and a measure $\mu$ (arbitrary, not assumed finite);
- explicit $P:\Omega\to\mathbb R$ and $(P_\ell)_{\ell\in\mathbb N^D}$;
- implicit $\alpha:\{0,\dots,D-1\}\to\mathbb R$ and $c_1\in\mathbb R$.

**Definitions used, expanded:**
- $\Delta P_\ell(\omega)=\sum_{T\subseteq\{d:\ell_d\ge1\}}(-1)^{|T|}P_{\ell-e_T}(\omega)$ (`crossDiff`, applied pointwise);
- $\alpha\cdot\ell=\sum_d\alpha_d\ell_d$ (`dot`);
- $2^{-\alpha\cdot\ell}$ is a real power.

**Hypotheses, in order:**
1. $\alpha_d>0$ for every $d$.
2. $P$ is $\mu$-integrable.
3. Every $P_\ell$ is $\mu$-integrable.
4. For every $\delta>0$ there is $n_0\in\mathbb N$ with $\big|\int(P_\ell-P)\,d\mu\big|<\delta$ whenever $\ell_d\ge n_0$ for all $d$.
5. $\big|\int\Delta P_\ell\,d\mu\big|\le c_1\,2^{-\alpha\cdot\ell}$ for every $\ell\in\mathbb N^D$.

**Conclusion:** the family $\big(\int\Delta P_\ell\,d\mu\big)_{\ell\in\mathbb N^D}$ is **unconditionally** summable with sum $\int P\,d\mu$. That is, for every $\delta>0$ there is a finite $F_0\subseteq\mathbb N^D$ such that every finite $F\supseteq F_0$ satisfies
$$\Big|\sum_{\ell\in F}\int\Delta P_\ell\,d\mu-\int P\,d\mu\Big|<\delta .$$
For real families this is equivalent to $\sum_\ell\big|\int\Delta P_\ell\,d\mu\big|<\infty$ together with the sum being $\int P\,d\mu$.

**Remarks:**
- No sign condition is placed on $c_1$. If $c_1<0$, hypothesis 5 is unsatisfiable, so that sub-case is vacuous. If $c_1=0$, every $\int\Delta P_\ell\,d\mu$ is $0$.
- With $\alpha_d>0$, hypothesis 5 bounds each term by $c_1 2^{-\alpha\cdot\ell}$, and $\sum_{\ell\in\mathbb N^D}c_12^{-\alpha\cdot\ell}=c_1\prod_d(1-2^{-\alpha_d})^{-1}<\infty$. This supplies the unconditional convergence; hypothesis 4 identifies the value.
- $D=0$: a one-point sum, and the conclusion is $\int P_\varnothing\,d\mu=\int P\,d\mu$.
- Not vacuous in general.

## `giles_theorem2_full`

**Outer data:**
- implicit $D\in\mathbb N$ with the instance `[NeZero D]`, i.e. $D\ge1$;
- implicit $\alpha,\beta,\gamma:\{0,\dots,D-1\}\to\mathbb R$.

The statement is universe-polymorphic: $\Omega$ below ranges over types in a fixed but arbitrary universe $u$.

**Definitions used, expanded:**
- $\eta=\max_d\dfrac{\gamma_d-\beta_d}{\alpha_d}$ (`mimcEta`).
- $D_2=\#\{d:(\gamma_d-\beta_d)/\alpha_d=\eta\}$ (`mimcD2`), with $1\le D_2\le D$.
- $\alpha\cdot\ell=\sum_d\alpha_d\ell_d$, and similarly for $\beta$ and $\gamma$ (`dot`).
- $\Delta P_\ell(\omega)=\sum_{T\subseteq\{d:\ell_d\ge1\}}(-1)^{|T|}P_{\ell-e_T}(\omega)$ (`crossDiff`, pointwise).
- $\operatorname{mimcBound}(\eta,e_1,e_2,\varepsilon)$ equals:
  - $\varepsilon^{-2}$ if $\eta<0$;
  - $\varepsilon^{-2}|\ln\varepsilon|^{e_1}$ if $\eta=0$;
  - $\varepsilon^{-2-\eta}|\ln\varepsilon|^{e_2}$ if $\eta>0$,

  with real powers.
- $\mathbb E[f]=\int f\,d\mu$ (Bochner integral).

**Outer hypotheses, in order:**
1. $\alpha_d>0$ for all $d$.
2. $\beta_d>0$ for all $d$.
3. $\gamma_d>0$ for all $d$.
4. $\beta_d/2\le\alpha_d$ for all $d$.

Hypothesis 1 is redundant given 2 and 4.

**Conclusion.** There exist real numbers $e_1,e_2$ — chosen depending only on $D,\alpha,\beta,\gamma$, before any probability space or random variable — such that both (I) and (II) hold.

**(I)** If $\beta_d/2<\alpha_d$ for **every** $d$, then
$$e_1=2D_2\quad\text{and}\quad e_2=(D_2-1)(2+\eta).$$
$D_2$ is cast to $\mathbb R$ before subtracting $1$, so there is no truncation; in any case $D_2\ge1$.

**(II)** For every type $\Omega$ (in universe $u$), every $\sigma$-algebra on $\Omega$, every probability measure $\mu$ on it, and all of the following data:
- $P:\Omega\to\mathbb R$;
- $(P_\ell)_{\ell\in\mathbb N^D}$ with $P_\ell:\Omega\to\mathbb R$;
- $(Y_{\ell,n})_{\ell\in\mathbb N^D,\,n\in\mathbb N}$ with $Y_{\ell,n}:\Omega\to\mathbb R$;
- $(\mathrm{Cost}_{\ell,n})_{\ell\in\mathbb N^D,\,n\in\mathbb N}$ with $\mathrm{Cost}_{\ell,n}:\Omega\to\mathbb R$;
- $V,C:\mathbb N^D\to\mathbb R$;
- $c_1,c_2,c_3\in\mathbb R$,

if all of the following hold (in this order):

- **(H1–H3)** $c_1>0$, $c_2>0$, $c_3>0$.
- **(H4)** $P$ is $\mu$-integrable.
- **(H5)** Every $P_\ell$ is $\mu$-integrable.
- **(H6)** For all $\ell$ and all $n\ge1$: $Y_{\ell,n}\in L^2(\mu)$.
- **(H7)** For every $N:\mathbb N^D\to\mathbb N$ with $N_\ell\ge1$ for all $\ell$: for all $\ell\neq\ell'$, $Y_{\ell,N_\ell}$ and $Y_{\ell',N_{\ell'}}$ are independent under $\mu$. This is pairwise independence only, not mutual. It is equivalent to: $Y_{\ell,n}$ and $Y_{\ell',n'}$ are independent for all $\ell\neq\ell'$ and all $n,n'\ge1$.
- **(H8)** For all $\ell$ and $n\ge1$: $\mathrm{Cost}_{\ell,n}$ is $\mu$-integrable.
- **(H9)** For all $\ell$ and $n\ge1$: $\mathbb E[\mathrm{Cost}_{\ell,n}]=n\cdot C_\ell$ ($n$ cast to $\mathbb R$).
- **(H10)** For all $\ell$ and $n\ge1$: $\operatorname{Var}(Y_{\ell,n})=V_\ell/n$ ($n$ cast to $\mathbb R$).
- **(H11)** For every $\delta>0$ there is $n_0\in\mathbb N$ with $\big|\mathbb E[P_\ell-P]\big|<\delta$ for all $\ell$ having $\ell_d\ge n_0$ for every $d$.
- **(H12)** For all $\ell$ and $n\ge1$: $\mathbb E[Y_{\ell,n}]=\mathbb E[\Delta P_\ell]$.
- **(H13)** For all $\ell$ and $n\ge1$: $\big|\mathbb E[Y_{\ell,n}]\big|\le c_1\,2^{-\alpha\cdot\ell}$. By (H12) this is the same as $|\mathbb E[\Delta P_\ell]|\le c_1 2^{-\alpha\cdot\ell}$.
- **(H14)** For all $\ell$: $V_\ell\le c_2\,2^{-\beta\cdot\ell}$.
- **(H15)** For all $\ell$: $C_\ell\le c_3\,2^{\gamma\cdot\ell}$.

then there is $c_4>0$ such that for every $\varepsilon$ with $0<\varepsilon<e^{-1}$ there exist a finite set $\mathcal L\subseteq\mathbb N^D$ and $N:\mathbb N^D\to\mathbb N$ with:
- $N_\ell\ge1$ for **every** $\ell\in\mathbb N^D$ (not only $\ell\in\mathcal L$);
- $$\mathbb E\Big[\Big(\sum_{\ell\in\mathcal L}Y_{\ell,N_\ell}-\mathbb E[P]\Big)^2\Big]<\varepsilon^2 \quad(\text{strict});$$
- $$\mathbb E\Big[\sum_{\ell\in\mathcal L}\mathrm{Cost}_{\ell,N_\ell}\Big]\le c_4\cdot\operatorname{mimcBound}(\eta,e_1,e_2,\varepsilon).$$

**Quantifier order:**
- $e_1,e_2$ are chosen first, uniformly over all probability spaces and data.
- $c_4$ is chosen after **all** instance data ($\Omega,\mu,P,P_\ell,Y,\mathrm{Cost},V,C,c_1,c_2,c_3$) but before $\varepsilon$.
- $\mathcal L$ and $N$ are chosen after $\varepsilon$ and may depend on everything, including $\mu$ and $\mathbb E[P]$. The statement is purely existential about $(\mathcal L,N)$ and prescribes no construction.

**Casts and conventions:**
- The sample sizes $N_\ell$ are natural numbers. $n$ is cast to $\mathbb R$ in (H9) and (H10).
- $2^{\pm\alpha\cdot\ell}$ etc. are real powers.
- By (H6) and (H8), the integrands in the conclusion are integrable. The Bochner "non-integrable gives $0$" convention therefore creates no loophole: the MSE is the genuine second moment, and the cost expectation equals $\sum_{\ell\in\mathcal L}N_\ell C_\ell$ by (H9).
- $Y_{\ell,0}$ and $\mathrm{Cost}_{\ell,0}$ are unconstrained but never used, since $N_\ell\ge1$.
- Nothing requires $Y_{\ell,n}$ to be an average of $n$ samples; only the stated mean, variance, $L^2$ and independence properties are assumed.

**Edge cases:**
- $D=0$ is excluded.
- For $D=1$: $D_2=1$ and $\eta=(\gamma_0-\beta_0)/\alpha_0$. In the strict case $e_1=2$ and $e_2=0$, so the bound is $\varepsilon^{-2}$, $\varepsilon^{-2}|\ln\varepsilon|^2$ or $\varepsilon^{-2-\eta}$ according to the sign of $\eta$.
- $V_\ell\ge0$ follows from (H10) with $n=1$.
- $C_\ell$ and the costs are not required to be nonnegative. They are only bounded above, which makes the hypotheses more general.
- The regime where some $\alpha_d<\beta_d/2$ is excluded by outer hypothesis 4.

**Observations (strength and possible unintended readings):**
1. **Boundary case not pinned down.** If $\alpha_d=\beta_d/2$ for at least one $d$, part (I) is vacuously true. $e_1,e_2$ are then arbitrary reals, only required to work uniformly for all instances. When $\eta\ge0$ this leaves the exponent of $|\ln\varepsilon|$ unspecified, so any finite exponent that works suffices; this is strictly weaker than an explicit formula. When $\eta<0$ the bound $\varepsilon^{-2}$ does not involve $e_1,e_2$, so the boundary case with $\eta<0$ is fully specified. `mimcD3` (the count of directions with $\alpha_d=\beta_d/2$) is defined in the packet but appears in no statement.
2. **Instance-dependent constant.** $c_4$ may depend on the entire instance, including $\mu$, $P$, $P_\ell$, $Y$, $\mathrm{Cost}$ and the qualitative convergence in (H11). It is not claimed to depend only on $c_1,c_2,c_3,\alpha,\beta,\gamma$. For each fixed instance the claim is an asymptotic $O(\cdot)$ bound on $\varepsilon\in(0,e^{-1})$.
3. **Redundancy.** Outer hypothesis 1 ($\alpha_d>0$) follows from 2 and 4.
4. **Not vacuous.** All hypotheses of (II) are jointly satisfiable. For example: one-point $\Omega$ with the Dirac measure, $P=P_\ell=Y=0$, $V=0$, $C_\ell=1$, $\mathrm{Cost}_{\ell,n}=n$ constant, $c_1=c_2=1$, $c_3=1$. Non-degenerate instances also exist. The conclusion is not trivially satisfiable in general: $\mathcal L=\varnothing$ gives MSE $=\mathbb E[P]^2$, which is not $<\varepsilon^2$ for all small $\varepsilon$ unless $\mathbb E[P]=0$.

- **`giles_theorem2_full`:**
  - The exponents $e_1,e_2$ are constrained only when $\beta_d/2<\alpha_d$ for all $d$. In the boundary case (some $\alpha_d=\beta_d/2$, allowed by the hypotheses) they are free existentials, so the log exponent is unspecified whenever $\eta\ge0$.
  - `mimcD3` is defined but unused by any statement.
  - $c_4$ is chosen after all instance data, so it may depend on the whole instance, not only on the constants and rates.
